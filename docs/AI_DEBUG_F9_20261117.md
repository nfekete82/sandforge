# Sandforge: F9 KI-Debug-Dashboard (17.11.2026)

## Start

Nach aktuellem Branch-Update und `bash scripts/install-bastion-pbr-test.sh`:

```bash
PORT=8111 npm run preview
```

Auf `http://127.0.0.1:8111/webgl-preview.html` die Taste **F9** drücken, um die KI-Anzeige oben rechts ein-/auszublenden.

Auf einem entfernten Testserver wird die Anzeige absichtlich nicht standardmäßig erzeugt. Für kontrollierte Fehlerdiagnose `?aiDebug=1` an die Preview-URL anhängen. `?aiDebug=0` schaltet sie auf externen Hosts ab.

## Anzeigen

- **Aktuelles Ziel:** tatsächliche `tactical.state.commander.mission` (Bastion, Zielgebäude, Auftragsdauer), strategische Phase und taktische Phase
- **Bastionen:** tatsächlich aktuell rot/blau/neutral, relativer Kontrollbalken; keine Demo-Zahlen
- **Einheiten:** überlebende KI-Truppen und reale Anteile Infanterie/Fahrzeuge/Luft; Hauptangriff, lokale Verteidigung, Nebenangriffe werden nach gültigen Gruppen-IDs gezählt
- **Ressourcen:** aktuelle echte Credits, Einnahmen pro 10 Sekunden; alle abgeschlossenen Produktionsgebäude mit laufenden `queueTypes`
- **Kontakt / Kampf:** nur momentan für Rot sichtbare feindliche Einheiten, Kampfeinschätzung, bekannte Rückschläge, zuletzt aufgezeichnete KI-Entscheidung
- **JSON:** kopiert eine Momentaufnahme von `captureAiDebug(game)` in die Zwischenablage. Dies ist ein Lesezugriff und speichert keinen Spielstand.

## Grenzen und Sicherheit

- Das Overlay existiert auf localhost immer, auf anderen Hosts nur mit `aiDebug=1`.
- F9 wird bei Eingabefokus in INPUT, TEXTAREA oder SELECT ignoriert.
- Die Telemetrie ist **rein lesend** und wird bei offenem Overlay maximal etwa alle 650 ms aktualisiert. In geschlossenem Zustand wird keine Momentaufnahme erzeugt.
- Kein Zugriff auf Gegnerdaten, die von Rot im normalen Spiel nicht sichtbar sind, außer den ohnehin öffentlichen Bastionsbesitzständen (wie die taktische Simulation).
- Der Debug-Zustand gehört nicht zur Simulation und ist nicht Teil des Savegames.
- Regressionssuite: `tests/webgl-ai-debug-20261117.test.mjs`; unabhängige CI über `Sandforge AI and combat balance (headless)`.
- Echtes Grafik-/Bedienungs-Smoke am Mac (insbesondere F9, JSON-Kopieren, Pause/HUD-Überdeckung) bleibt als Browserprüfung erforderlich.

## Fehlersuche

Bei einer untätigen KI Dashboard öffnen, **F9-Snapshot als JSON kopieren** und zusammen mit Kartenseed und Zeitpunkt weitergeben. Damit sind die tatsächliche Auftragsphase, Truppen und Produktionslisten nachvollziehbar.
